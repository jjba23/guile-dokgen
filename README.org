/Guile Dokgen/ is a command-line program and accompanying library that
extracts the API documentation of [[https://www.gnu.org/software/guile/][GNU Guile]] Scheme modules and writes it
as Texinfo.  Point it at a module or a directory of modules, and it renders
every exported procedure, macro, variable and parameter object with its
docstring.

#+begin_src sh
dokgen api src/mylib
#+end_src

The result is ~doc/api/index.texi~ by default, ready for ~texi2any~.  The
manual is in [[file:manual/main.texi][manual/main.texi]]; ~maak manual~ builds it as HTML.

* Install

With Guix, from the [[https://github.com/jjba23/guix-jointhefreeworld][jointhefreeworld channel]]:

#+begin_src sh
guix install guile-dokgen
#+end_src

From a checkout, there is nothing to build: ~./bin/dokgen --help~ runs the
sources in place.  The dependencies are Guile 3.0, ~guile-config~ and
~guile-lib~; ~maak install~ puts the launcher under ~$PREFIX/bin~.

* Development

The development environment is pinned.  [[file:channels.scm][channels.scm]] fixes the Guix revision
and [[file:manifest.scm][manifest.scm]] lists the tools, and every [[https://codeberg.org/jjba23/maak][Maak]] task runs inside
~guix time-machine -C channels.scm -- shell -m manifest.scm~, so a task means
the same thing on every machine.

#+begin_src sh
maak            # list the tasks
maak test       # run the test suites
maak check      # compile every module
maak docs       # regenerate manual/api/index.texi from the sources
maak docs-check # fail when the committed reference is stale
maak version-check # fail when a quotation of the version drifted
maak deploy     # publish the page and the manual
maak manual     # build the HTML manual into reports/manual
maak repl       # a REPL with the library on the load path
#+end_src

The layout:

| Path           | What it holds                                         |
|----------------+-------------------------------------------------------|
| ~src/dokgen/~ | the library: reader, templates, writer, CLI           |
| ~bin/dokgen~  | the launcher                                          |
| ~tests/~         | one SRFI-64 suite per module                          |
| ~etc/~           | the test runner that turns failures into exit codes   |
| ~manual/~        | the Texinfo manual; ~api/~ is generated               |
| ~website/~       | the project page                                      |
| ~maak.scm~       | the tasks, and the generator of [[file:AGENTS.md][AGENTS.md]]            |

See [[file:CONTRIBUTING.md][CONTRIBUTING.md]] for how to send a change, and
[[file:VISION.md][VISION.md]] for where the project is going.
