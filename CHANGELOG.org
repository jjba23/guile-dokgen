Notable changes, newest first.  Releases before 0.5.0 were made by the
original author; their record is the version history in the manual.

* Unreleased

* 0.5.0 — 2026-11-17, hard fork

** Changed

- The project is now a hard fork under new maintainership.  The license changed
  from the public domain to the MIT License; every source file carries an SPDX
  header and ~LICENSE~ holds the text.  The original author is credited in the
  README and the manual.
- The layout follows [[https://github.com/jjba23/sift][sift]]: sources in ~src/~, the launcher at ~bin/documenta~
  (replacing ~documenta.scm~), helpers in ~etc/~.
- Development moved to Maak (~maak.scm~) running in a pinned Guix
  (~channels.scm~ for ~guix time-machine~, ~manifest.scm~, ~guix.scm~), replacing
  ~build-manual.sh~.
- The website and the manual no longer point at the original author's pages.

** Added

- ~AGENTS.md~, generated by ~maak agents~, and ~CONTRIBUTING.md~.
- ~etc/run-test.scm~, so a failing SRFI-64 suite fails ~maak test~.
